# Saad Waleed portfolio

Personal site for [saadadmalik.github.io](https://saadadmalik.github.io). Visual language inspired by [EVAA](https://www.evaa.sg/), not a clone.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

GitHub Pages can serve the built `docs/` folder (Settings → Pages → Deploy from branch → `/docs`), or the included Actions workflow.
